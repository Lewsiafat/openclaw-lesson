Step 0 / 9 · 前言

為什麼選 OpenClaw？這堂課要做什麼？

OpenClaw 是一套基於 TypeScript / Node.js 的開源 AI Agent 框架， 支援超過 50 種平台整合（Telegram、WhatsApp、Discord 等）， 並且原生支援 Windows — 不需要 WSL2 或 Docker。

這堂課會帶你在 60 分鐘內完成：安裝 Node.js → 安裝 OpenClaw CLI → 申請 API Key → 初始化設定 → 第一次對話 → 接通 Telegram。
