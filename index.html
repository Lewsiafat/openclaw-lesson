Step 0 / 9 · 前言

為什麼選 OpenClaw？這堂課要做什麼？

OpenClaw 是什麼？

OpenClaw 是一套用 TypeScript / Node.js 寫的開源 AI Agent 框架。 你可以把它想成「自己架一個 AI 助理」——不是用別人的平台，而是完全跑在你自己的電腦或伺服器上。

  • 支援超過 20 種平台整合（WhatsApp、Telegram、Slack、Discord、LINE、Signal、iMessage、Google Chat、Microsoft Teams、Matrix 等）
  • Windows 可用：npm 安裝原生支援，daemon 與 gateway 建議搭配 WSL2 以獲得最佳體驗
  • 開源、免費、可自行修改
  • 透過 Skills 系統讓 agent 學會新能力
⚠️ 關於 WSL2：OpenClaw 官方建議「macOS、Linux、Windows（via WSL2；強烈推薦）」。 基本的 npm install 和 CLI 指令在 Windows 原生 PowerShell 即可運作， 但 daemon 和 gateway 在 WSL2 環境下運行最穩定。本課程以 Windows 原生 PowerShell 流程為主， 遇到問題時可考慮改用 WSL2。

跟其他方案比較

這堂課結束後你會有什麼

  1. 已安裝 Node.js 22+ 和 OpenClaw CLI 的 Windows 電腦
  2. 一組 AI API Key，可控制使用費用
  3. 已完成初始化的 OpenClaw agent
  4. 成功在終端機與 agent 對話
  5. 接通 Telegram bot，手機也能聊

Step 1 / 9 · 確認前置需求

~5 分鐘，確保你的環境符合最低要求

需要準備的東西

  • ✅ Windows 11（22H2 或更新）
  • ✅ 管理員權限（能安裝軟體）
  • ✅ 穩定網路（需下載約 100MB）
  • ✅ 瀏覽器（Chrome 或 Edge 皆可）
  • ✅ Telegram 帳號（Step 6 會用到）
  • ✅ 信用卡或 PayPal（申請 API Key 時需要少量儲值，約 $5 美元）

確認 Windows 版本

按 Win + R，輸入以下指令並按 Enter：

winver

應該看到「Windows 11」以及版本號（22H2 或更新）。

確認管理員權限

在開始功能表搜尋「PowerShell」，對它按右鍵選擇「以系統管理員身分執行」。

如果有跳出 UAC 確認視窗（問你是否允許），代表你有管理員權限，可以繼續。

遇到問題？
  • 看到「Windows 10」：本課程以 Windows 11 為主，部分截圖可能不同，但流程應相同。
  • 沒有管理員權限：請聯絡電腦管理員，或使用個人電腦。
  • 沒有 Telegram 帳號：現在就去手機下載 Telegram 並註冊，免費。

一切都確認好了嗎？繼續！

Step 2 / 9 · 安裝 Node.js 22+

~10 分鐘，OpenClaw 需要 Node.js 22.14 以上

方法一：官方安裝程式（推薦新手）

  1. 前往 https://nodejs.org/
  2. 點選左邊的 LTS（長期支援版）下載按鈕
  3. 執行下載的 .msi 安裝程式
  4. 全部選預設值，一直按「Next」，最後按「Install」
  5. 安裝完成後，重新開啟 PowerShell（這步很重要）

方法二：nvm-windows（推薦進階用戶）

nvm-windows 讓你日後可以輕鬆切換 Node.js 版本。

  1. 前往 nvm-windows 下載頁面
  2. 下載最新版的 nvm-setup.exe
  3. 執行安裝程式，使用預設路徑
  4. 安裝完成後，以系統管理員開啟新的 PowerShell，輸入：
nvm install 22
nvm use 22

驗證安裝成功

不管用哪個方法，完成後在 PowerShell 輸入：

node --version
npm --version

應該看到類似這樣的輸出：

v22.17.1
10.9.2

Node.js 版本必須是 v22 以上。

遇到問題？
  • node: command not found 或找不到指令
    你可能忘記重新開啟 PowerShell。完全關掉舊視窗，再重新用管理員身分開啟新的 PowerShell。
  • 防毒軟體阻擋安裝
    暫時關閉 Windows Defender 即時保護（設定 → 隱私權與安全性 → Windows 安全性），安裝完再開回來。
  • 版本顯示 v18 或更舊
    如果系統已有舊版 Node.js，使用 nvm-windows 的方法，並執行 nvm use 22 切換版本。

Step 3 / 9 · 安裝 OpenClaw CLI

~5 分鐘，用 npm 全域安裝 OpenClaw 命令列工具

安裝指令

在系統管理員身分的 PowerShell 中執行：

npm install -g openclaw@latest

安裝過程中會看到一堆文字滾動，這是正常的。等它完成（回到命令提示符號）即可。

驗證安裝

openclaw --version

應該看到版本號，例如 openclaw/2.x.x。

順便更新 npm（可選）

如果你的 npm 版本偏舊，可以一併更新：

npm install -g npm@latest
遇到問題？
  • EACCES 或 permission denied 錯誤
    請確認你是用系統管理員身分開啟 PowerShell（對 PowerShell 圖示按右鍵 → 以系統管理員身分執行）。
  • 安裝很慢或逾時
    npm 有時候慢，正常等候即可。如果一直逾時，試試換用 npx 安裝：npx openclaw@latest
  • openclaw: command not found
    關閉 PowerShell，重新以系統管理員身分開啟，再輸入 openclaw --version。
  • Windows Defender SmartScreen 警告
    點選「更多資訊」→「仍要執行」。OpenClaw 是開源軟體，無惡意程式。

Step 4 / 9 · 申請 API Key

~10 分鐘，取得讓 AI 模型說話的鑰匙

什麼是 API Key？

API Key 就像一張門票，讓 OpenClaw 可以去敲 AI 公司（例如 Anthropic 或 OpenAI）的門， 叫模型幫你回答問題。使用多少算多少費用，你可以完全控制。

推薦：OpenRouter（最簡單）

OpenRouter 是一個 AI 模型的聚合平台，一組 Key 可以用多種模型，包含 Claude、GPT-4、Gemini。

  1. 前往 https://openrouter.ai/
  2. 點選右上角「Sign In」→ 用 Google 帳號或 Email 註冊
  3. 登入後點選右上角你的頭像 → 「API Keys」
  4. 點「+ Create Key」，輸入任意名稱（例如 openclaw-key）
  5. 複製產生的 Key（格式類似 sk-or-v1-xxxxxxxx）
  6. 回到側邊欄點「Credits」→ 儲值至少 $5 美元
⚠️ 重要：API Key 只會顯示一次！複製後立刻貼到記事本存好，關掉頁面就看不到了。

備案一：Anthropic（直連 Claude）

  1. 前往 https://console.anthropic.com/
  2. 註冊帳號並驗證 Email
  3. 前往「API Keys」→ 建立新 Key
  4. 「Billing」→ 儲值

備案二：OpenAI（直連 GPT）

  1. 前往 https://platform.openai.com/
  2. 登入後前往「API Keys」→ 建立新 Key
  3. 「Billing」→ 儲值
遇到問題？
  • OpenRouter 要求信用卡驗證
    這是正常的付費流程。也可以選 Anthropic，有些帳號有免費試用額度。
  • 不確定要選哪個模型
    先用 OpenRouter，預設模型通常是 Claude 3.5 Sonnet，品質很好。

API Key 已經安全保存了嗎？下一步要用它！

Step 5 / 9 · 初始化設定

~10 分鐘，執行 onboard 精靈完成 API Key 設定與頻道選擇

⚠️ 先備好 Telegram Bot Token！ 精靈在「Select channel」步驟會要你貼入 Telegram Bot Token。 建議先跳到 Step 6 第一部分建立 Telegram bot、取得 Token，再回來執行這個步驟。

執行 onboard 精靈

在系統管理員身分的 PowerShell 中執行：

openclaw onboard --install-daemon

精靈會依序出現以下 7 個畫面，照表操作：

選完「Hatch in Terminal」後，gateway 會自動啟動，TUI 介面隨即開啟。你的 agent 已經在線上了。

「Search provider」跳過了，AI 怎麼辦？

跳過 provider 代表 onboard 結束後 agent 還沒有 AI 模型可以呼叫。 TUI 開啟後，在 TUI 裡執行 /configure 或在另一個視窗跑：

openclaw configure

選擇 openrouter，貼入你在 Step 4 取得的 API Key，儲存後 agent 就能跟 AI 說話。

遇到問題？
  • onboard 沒有互動，直接跳出
    以系統管理員身分重新開啟 PowerShell，再跑一次 openclaw onboard --install-daemon。
  • TUI 沒有出現，停在 Step 7
    確認有選「Hatch in Terminal」而不是其他選項。重新執行 onboard 再試。
  • 想手動編輯設定檔
    設定檔通常在 %USERPROFILE%\.openclaw\config.json，用記事本直接編輯也可以。

Step 6 / 9 · 接通 Telegram

~10 分鐘，建立 Telegram bot 並驗證連線

第一部分：建立 Telegram Bot

  1. 打開 Telegram，在搜尋欄輸入 @BotFather
  2. 點進去，按「Start」或輸入 /start
  3. 輸入 /newbot
  4. 依提示輸入你的 bot 全名（顯示名稱），例如：My OpenClaw Agent
  5. 再輸入 bot 的 username（必須以 bot 結尾），例如：myopenclaw_bot
  6. BotFather 會給你一段 Bot Token，格式類似：1234567890:ABCdef...
  7. 複製這個 Token，貼到記事本備用
⚠️ Token 請小心保管：不要分享給別人，否則別人可以控制你的 bot。

第二部分：驗證 Telegram 連線

完成 Step 5 onboard 後，TUI 已自動開啟、gateway 已在背景運作。現在去 Telegram 確認連線：

  1. 打開 Telegram，搜尋你剛才建立的 bot username（例如：@myopenclaw_bot）
  2. 點進去，發一則訊息：
/start

成功標準：bot 在 10 秒內回覆，內容是 agent 的自我介紹。

遇到問題？
  • Bot 沒有回覆
    確認 Step 5 的 TUI 還在跑（那個 PowerShell 視窗沒有關掉）。TUI 就是 gateway——關掉視窗等於關掉 agent。
  • Token invalid 錯誤
    回去 BotFather，點 /mybots → 你的 bot → API Token，重新複製完整的 token，再跑一次 openclaw onboard --install-daemon 重新設定。
  • Bot 找不到
    Telegram 搜尋有時候慢，試著直接輸入完整的 @username。
  • TUI 已關掉，想重新啟動 agent
    重新開啟 PowerShell，執行： 
    openclaw gateway --port 18789 --verbose
    這樣可以手動啟動 gateway，不需要重跑 onboard 精靈。

Step 7 / 9 · 第一次對話

~5 分鐘，跟你的 AI agent 說第一句話

從 Telegram 發訊息

打開 Telegram，找到你的 bot，試試輸入這幾句：

你好，請用繁體中文跟我自我介紹
請問現在幾點？

成功標準：agent 能用完整的繁體中文句子回覆，內容合理（不是錯誤訊息）。

也可以在終端機測試

開啟另一個 PowerShell 視窗（gateway 那個不要關），用 agent 指令直接對話：

openclaw agent --message "你好，請用繁體中文跟我自我介紹" --thinking high

這會送出一則訊息給 agent 並顯示回覆。--thinking high 讓 agent 用更多推理能力回答。

遇到問題？
  • 回覆是英文
    在訊息中加上「請用繁體中文回答」，或重新執行 onboard 設定語言偏好。
  • API 錯誤：401 Unauthorized
    API Key 可能打錯了。重新執行 openclaw onboard --install-daemon 更正。
  • API 錯誤：429 Too Many Requests
    帳戶沒有餘額。回到 OpenRouter / Anthropic 的 Billing 頁面儲值。
  • 沒有任何回覆，就一直等
    確認 Step 5 的 TUI 視窗還在跑（或手動執行 openclaw gateway --port 18789 --verbose），網路連線正常，再試一次。

太棒了！agent 能說話了。繼續做最後驗收！

驗收清單

Step 9 / 9 · 加碼

~5 分鐘，你已經建好地基，現在來看看蓋得多高

Skills 系統

Skills 是讓 agent 學會新技能的方式。每個 Skill 是一個 Markdown 檔， 描述 agent 遇到特定指令時該做什麼。

例如：建立一個「每天早上 8 點傳天氣報告」的 skill，或「幫我把英文翻譯成中文」的 skill。

openclaw skills list

接通更多平台

OpenClaw 的 gateway 是統一入口：在 onboard 時設定好各平台，然後用一條指令啟動全部。 不需要為每個平台單獨啟動。

設定新平台的流程

  1. 重新執行 onboard 精靈，選擇要新增的頻道：
openclaw onboard --install-daemon
  1. 或使用 pairing 指令配對（部分平台支援）：
openclaw pairing approve telegram <code>
  1. 啟動 gateway，所有已設定的平台會一起上線：
openclaw gateway --port 18789 --verbose

支援的平台

自訂 System Prompt

你可以在設定檔中指定 agent 的個性和限制。 例如讓它只回答工作相關問題，或讓它扮演特定角色。 

openclaw config set system_prompt "你是一個專業的財務助理，只回答財務相關問題。"

排程任務

讓 agent 自動執行週期性任務：

openclaw schedule add --cron "0 8 * * *" --task "發送今日天氣報告到 Telegram"

診斷與維護

遇到問題時，先跑診斷指令：

openclaw doctor

它會檢查所有元件的健康狀態，並告訴你哪邊需要修正。

多 Agent 協作

進階玩法：建立多個有不同職責的 agent，讓它們互相合作。 例如一個負責研究、一個負責寫作、一個負責審核。 這是 OpenClaw 的 A2A（Agent-to-Agent）功能預覽。

下一步建議

  1. 玩一週：每天想一個用 agent 幫你做的事，看它能做到什麼程度
  2. 建第一個 Skill：把你常做的重複性工作自動化
  3. 加入社群：在 GitHub Discussions 分享你的用法、看別人的 Skill
  4. 接通第二個平台：試試 WhatsApp 或 Discord
